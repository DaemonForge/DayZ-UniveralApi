☁️ Cloudflare Tunnel Setup Guide

What is Cloudflare Tunnel?

Cloudflare Tunnel lets you securely expose this service to the internet without opening any ports on your router or firewall. Traffic is routed through Cloudflare's network, which also provides DDoS protection and SSL automatically.

💰 Cost

Cloudflare Tunnel is part of Cloudflare Zero Trust, which has a free tier supporting up to 50 users. This is more than enough for most DayZ server setups. You do not need a paid plan unless you require advanced access policies or have a very large team.

You will need a domain name (even a cheap one) added to your Cloudflare account. Domain registration through Cloudflare starts around ~$10/year for common TLDs. If you already own a domain, you can transfer its DNS to Cloudflare for free.

⚙️ Before You Start — Service Settings

Before setting up the tunnel, configure this service:

  1. Set Certificate Type to Self Signed in the SSL/TLS section above. Cloudflare handles public SSL for you — the self-signed cert is only used for the local connection between cloudflared and this service.
  2. Note your Port number (currently 443). You'll need this when configuring the tunnel hostname.
  3. Save settings and restart the app before proceeding.

📋 Step-by-Step Setup

  1. Create a Cloudflare account (if you don't have one) at dash.cloudflare.com.
  2. Add a domain to your Cloudflare account and update your domain registrar's nameservers to Cloudflare's (Cloudflare will walk you through this).
  3. Open Zero Trust dashboard — go to one.dash.cloudflare.com and select the free plan when prompted.
  4. Create a tunnel:
    • Navigate to Networks → Tunnels.
    • Click Create a tunnel.
    • Select Cloudflared as the connector type.
    • Give it a name (e.g. my-dayz-server).
  5. Copy the tunnel token — on the "Install connector" step, Cloudflare shows a command like:
    cloudflared.exe service install eyJhIjoiNj...
    You can copy the entire command — this app will automatically extract just the token for you. Or copy just the eyJ... part.
  6. Configure the public hostname:
    • On the next step, add a Public Hostname.
    • Set a subdomain (e.g. api) and select your domain.
    • Leave Path empty.
    • Under Service:
      • Type: HTTPS
      • URL: localhost
    • Expand Additional application settings → TLS and enable No TLS Verify (required because the service uses a self-signed certificate).
    • Click Save tunnel.
  7. Paste the token here — back in these settings:
    1. Paste the token into the Tunnel Token field above.
    2. Check Enable Tunnel.
    3. Click the Save button (bottom-right) and restart the app.
    4. The tunnel will connect automatically on next launch (if Auto-Start is on), or click Start.

🎮 DayZ Mod Configuration

Once the tunnel is running, update your DayZ mod config file (UF/UFramework.json in your server profile):

"ServerURL": "https://api.yourdomain.com"

Replace with your actual subdomain + domain from step 6 above (e.g. https://mytestserver.dayz.onl). No port number is needed — Cloudflare routes traffic on standard HTTPS port 443.

🔒 Security Notes

  • The tunnel token is stored locally in your config and is never shared with anyone.
  • Cloudflare handles public SSL — your DayZ mod connects via HTTPS to your tunnel URL.
  • You can add access policies in Zero Trust to restrict who can reach your service.
  • The cloudflared binary is downloaded from GitHub releases and checks for updates automatically every 24 hours.

💡 Tips

  • Enable Auto-Start on Launch so the tunnel connects whenever the service starts.
  • If the tunnel shows errors, check that your token hasn't been revoked in the Zero Trust dashboard.
  • If you change the Port in settings, update the URL in your Cloudflare tunnel hostname config to match.
  • You do not need to open any firewall ports — that's the whole point of the tunnel!
